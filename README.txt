DOTS WAR — файлы PWA (установка игры на главный экран телефона из браузера, офлайн-режим)

Что положить в папку сайта рядом с index.html (игра dots-war.html должна называться index.html):
  manifest.json          — описание приложения (имя, иконки, цвет)
  sw.js                  — service worker: кэш для офлайн-игры и обновления
  icon-192.png           — иконка для Android / Chrome
  icon-512.png           — иконка для Android / Chrome
  icon-maskable-512.png  — иконка с безопасной зоной (круглые/скруглённые формы Android)
  favicon.png            — иконка вкладки браузера

Пример для GitHub Pages: репозиторий dots-game → https://logicreate.github.io/dots-game/
  dots-game/
    index.html        (переименованный dots-war.html)
    manifest.json
    sw.js
    icon-192.png
    icon-512.png
    icon-maskable-512.png
    favicon.png
    preview.png       (уже есть — картинка для ссылки-превью)

После загрузки:
  Android (Chrome): открыть сайт → меню ⋮ → «Установить приложение» / «Добавить на главный экран».
  iPhone (Safari):  открыть сайт → кнопка «Поделиться» → «На экран „Домой“».
  Игра откроется на весь экран без адресной строки, режим против ИИ работает без интернета.

Обновление игры: просто замените index.html на сайте. При следующем открытии с интернетом
service worker подтянет новую версию автоматически (сеть — приоритет, кэш — только офлайн).
Если меняете sw.js — увеличьте номер в CACHE = 'dotswar-v2', чтобы старый кэш очистился.

Важно: service worker работает только по https:// (GitHub Pages подходит) и не работает при
открытии файла напрямую (file://) и внутри Android/iOS-обёртки — там он просто не активируется,
игра при этом работает как обычно.
